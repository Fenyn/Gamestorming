# UI

One theme for every screen: the HUD, the title screen, the end-of-day card, the POS screen and the world labels that act as UI (station status, speech, floating text, the cash drawer readout).

## Rules

- Show only what the player needs now. If the world already shows it (a gauge on a prop, the clock on the brew timer), the HUD does not repeat it.
- Don't explain the obvious, and don't use taglines.
- Text is plain and in sentence case. Keys are written `[Key] action` and drawn as key caps.
- Exclamation marks are only for customer speech.

## Pieces

| File | What it is |
|---|---|
| `scripts/ui/ui_style.gd` | Tokens: palette, type sizes and weights, spacing, radii, and the names of the theme variations. Builds the theme with godot_base's `StyleFactory`. |
| `assets/ui/ui_theme.tres` | The project theme (`gui/theme/custom`). Generated by `tools/build_ui_theme.gd`, and kept on later runs so editor tweaks survive. `-- --force` rebuilds it. |
| `assets/fonts/nunito/` | Nunito, a variable font. `UiStyle.font(weight)` returns it at a weight. |
| `scenes/ui/hud.tscn`, `scripts/ui/hud.gd` | Status chip (clock and till, or Prep and the open-shop key), the prompt under the crosshair, the cup ticket, the controls strip and assist readout, review toasts. |
| `scripts/ui/ticket_card.gd` | The HUD copy of the cup ticket: code, drink and steps, with the next step marked. Tab shows how to do a step. |
| `scenes/ui/day_summary.tscn` | End-of-day card. |
| `scripts/ui/key_hint.gd` | Turns `"[E] Grind"` text into key cap rows. |
| `scripts/ui/ui_icon.gd` | Drawn tick, arrow, bullet, stars, bean and crosshair (Nunito lacks those glyphs). |
| `scripts/ui/title_screen.gd` | Title screen on godot_base's `MainMenuBase`. |

## Palette

| Token | Use |
|---|---|
| `ROAST` | Panels and chips, translucent over the world |
| `CREMA` | Main text on dark |
| `STEAM` | Secondary text |
| `GREEN`, `GREEN_DEEP` | The one accent (the roof sign's green): selection, money in, done |
| `AMBER` | Warnings and good reviews |
| `RED` | Failures |
| `PAPER`, `INK` | The cup ticket |

## Prompts and status labels

Stations keep their status in a `Label3D` (`StationUtils.create_status_label`). While you look at a station, that text shows in the HUD prompt and the world label hides. Elsewhere, the world label pops up for 3 seconds when the text changes, so alerts reach you from across the shop. Customers and anything else can give a prompt with `get_prompt()`.

Locked views (mini-games, the POS, the cash drawer) fill the controls strip from `get_controls_hint()` on whatever locked the camera.
