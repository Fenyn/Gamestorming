# Zenith card roster (art pass)

Generated 2026-09-16 from `data/cards/starter/starter_set.json` and the six decks in `data/decks/` by a scratch script; the effect column is the engine's own rules text, so it matches what the card face shows in the client. This is the one file in the repo allowed to name source cards (agreed 2026-09-16); keep them out of everything else. The same rows live in `card_roster.csv`.

Names are still placeholders until tone is approved (see `data/cards/README.md`). One row per art image: duelists get a row per aspect because each aspect is its own face. Art goes in `assets/card_art/<id>.png` (`<id>_a<aspect>.png` for duelist aspects); see `README.md`.

Houses: Ashmark = Ember, Pact. Quarr = Steel, Pact. Draik Company = Shade, Pact. Rooke = Tide, Vigil. Vale = Freestyle, Vigil. Corven = Storm, Pact. Cards named after a house or person are Signature cards for that duelist.
