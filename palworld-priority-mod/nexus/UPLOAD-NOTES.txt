Each is a single-component archive rooted at ue4ss/Mods/<Name>/ — this is the
layout the official Vortex Palworld extension parses (one tracked mod per
archive; enabled.txt is ignored by Vortex and used by manual installs).
The zips contain ONLY the ue4ss tree — no loose root files. A shared root
file (e.g. INSTALL.txt) in both archives deploys to the same path and makes
Vortex flag a mod conflict between the two files. Install instructions live
on the mod page instead (the release/ folder keeps INSTALL.txt for the
manually-shared friend bundle only).

behind the DEBUG flag at the top of each main.lua).
