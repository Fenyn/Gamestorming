# Exploration HUD icons

Copied unchanged from Kenney Board Game Icons 1.1, `PNG/Default (64px)` (`F:/UnityNVME/Art/Sprites/UI/kenney_board-game-icons`). They are white glyphs; `CaptionButton.CaptionIcon` draws them in the caption's colour.

- `pawns.png`: Party
- `book_open.png`: Journal
- `flask_full.png`: healing potions
- `pouch.png`: gold
- `hourglass.png`: Short rest (ten minutes)
- `campfire.png`: Make camp
- `arrow_right.png`: leave the floor
