# Giant Viper

Medium snake (Monster Core classification), with 61 x 45 visible resting bounds on a 96 x 64 canvas. The heavier coil and broad triangular head distinguish it from the Tiny regular Viper. Runtime scale is .02 world units per source pixel with a four-pixel ground margin and right-facing source art. Padding leaves room for the strike without resizing the native canvas.

The built-in image generation tool supplied `construction-reference.png`; see `generation-prompt.txt` for the exact prompt. That initial prompt described the requested heavier anatomy before the Monster Core size was checked; the final sprite is Medium, not Large. The generated reference has a soft halo and excess light accents, so it supplies construction only. `tools/build_giant_viper.lua` authors native Aseprite polygon shapes, with no imported generator texture or halo.

Deliverables include layered `giant-viper-base.aseprite`, `giant-viper-idle.aseprite`, `giant-viper-attack.aseprite`, transparent native `giant-viper-base.png`, integer previews, equal-scale reference lineup, silhouette, five idle PNGs, six attack PNGs, JSON timing manifests, frame sheets and GIF previews. Runtime PNGs and SpriteFrames resource are in `assets/sprites/enemies/giant_viper_base`.

Eight named layers separate tail, rear coil, front coil, continuous raised neck, skull, hinged lower jaw, eye/fangs, and an empty equipment layer. Rear coil and tail continue behind the front loop and neck. Every pose retains the neck-to-coil connection. Idle is a 2.25-second five-frame loop with a subtle one-pixel lift; a snake does not blink. Attack is .58 seconds with contact at zero-based frame 2 (.18 seconds), a tapered bite cavity, visible fangs, and exact recovery. `attack_giant_viper_bite.tscn` authors eight bite accents ahead of the head.

Review compared actual rat, goblin, regular wolf and regular viper at identical source pixel scale with ground contacts aligned. The first native pass had a weak inner-neck shadow compared with the regular Viper. A focused value correction deepened that existing region without changing the alpha mask or adding texture. `neck-depth-before-after-6x.png` records this pass. Dark shapes now identify the recessed inner coil and the neck side turned away from the upper-left light; the pale belly follows the forward/inner neck into the front coil. No patterned bands or scale texture were added.

Parent and independent review identified parallel pale jaw rows in the first attack pass. The final correction retains a diagonal cheek-to-tip jaw at contact and follow-through, shades the open upper lip, and replaces the repeated tooth row with one pronounced upper fang plus a small chin-tip light. `before-jaw-review/attack-frames-4x.png` preserves the preceding version. Both reviews found the corrected bite readable; base, coil and neck art remain unchanged by that mouth correction.

Validation reopens all three masters, checks eight layers and intended frame counts, compares every rendered frame to its PNG, checks binary alpha and exact idle/base/attack recovery. Separate connectivity, ground-registration, palette, and runtime/source checks are recorded with the review. Runtime combat placement and VFX are integration checks rather than claims from image export.

Rebuild with Aseprite `--batch --script tools/build_giant_viper.lua`, optionally preceded by `--script-param root=<absolute-delve-path>`. The script overwrites generated masters and PNGs; preserve manual edits or encode corrections in the builder first. It preserves the authored runtime resource.
