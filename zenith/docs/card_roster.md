# Zenith card roster (art pass)

Generated 2026-09-16 from `data/cards/starter/starter_set.json` and the six decks in `data/decks/` by a scratch script; the effect column is the engine's own rules text, so it matches what the card face shows in the client. This is the one file in the repo allowed to name source cards (agreed 2026-09-16); keep them out of everything else. The same rows live in `card_roster.csv`.

Names are still placeholders until tone is approved (see `data/cards/README.md`). One row per art image: fighters get a row per tier because each tier is its own face. Art goes in `assets/card_art/<id>.png` (`<id>_t<tier>.png` for fighter tiers); see `README.md`.

Houses: Ashmark = Ember, Knave. Quarr = Steel, Knave. Draik Company = Shade, Knave. Rooke = Tide, Knight. Vale = Freestyle, Knight. Corven = Storm, Knave. Cards named after a house or person are Signature cards for that fighter.
