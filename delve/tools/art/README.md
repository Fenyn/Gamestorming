The active UI chrome uses SVG nine-patches generated by `ui_chrome.py`.
Run `python delve/tools/art/ui_chrome.py` from the workspace root to regenerate
buttons, keyboard focus corners, result frames, and dividers. Edit the palette
in that script for those assets; text and panel colors live in the shared themes.
See `design/ui_palette.md` for color roles and contrast values.

The Aseprite artwork below is retained as an alternate treatment. Its PNG exports
are no longer referenced by the active shared themes.

Fantasy UI artwork is authored and exported in Aseprite.

Editable sources and runtime PNGs live in `assets/ui`: `button_*.aseprite`,
`result_frame.aseprite`, and `result_rule.aseprite`. Buttons have separate leather
and brass-detail layers; focus is a transparent corner overlay.

Open a source in Aseprite and export its matching PNG after editing. Godot uses
nine-patch StyleBoxTextures, preserving 12px horizontal / 10px vertical button
ends and 32px result-frame corners. Keep decorative marks within these margins.

`fantasy_ui.lua` regenerates the initial artwork using Aseprite's scripting API:

    Aseprite.exe --batch --script-param out=<absolute assets/ui path> --script fantasy_ui.lua

Shared themes cover normal, hover, pressed, disabled, and keyboard focus states.
The camp departure action uses the brass accent surface. `result_panel.tres` is
shared by combat rewards and the expedition summary.

Render `scenes/dev/fantasy_ui_spike.tscn` to review victory and defeat layouts.
